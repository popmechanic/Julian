# voice scratch output

Renders land here (`scripts/voice/render.mjs` convention; the server serves
this path, so browser doors can be handed a URL). WAVs here are ephemeral
and git-ignored. A render worth keeping is *promoted*: copied elsewhere in
`memory/` and committed deliberately together with the exact notation string
that produced it — a kept sound must be replayable, not just playable
(same rule as `memory/drawings/`).
